# 构建与部署指南（中文主入口）

本文件保留原文件名以兼容已有书签；完整内容已整理到[构建与部署手册](构建与部署手册.md)。请不要再按照历史英文安装文档中的旧命令操作。

## 最短路径

Linux：

```sh
scripts/build-deploy-linux.sh
```

macOS 自用：

```sh
scripts/macos/build-deploy-self-use.sh
```

两条脚本都不会启动 Docker。Linux 只在安装阶段使用 `sudo`；macOS 只会把旧 app 可恢复地移到废纸篓，不会自动激活系统扩展或修改 TCC。

## 手工流程

请按[构建与部署手册](构建与部署手册.md)执行。手工流程包含依赖安装、普通用户编译、签名/entitlement 检查、服务启动、GUI 权限、验收和卸载；脚本只是这些步骤的安全编排，不会绕过人工授权。
