# SSH 私钥访问模型

## 保护目标

普通进程读取已登记 SSH 私钥时，在文件成功打开前进入确认；批准只产生短时、精确绑定到进程树、用户、私钥文件身份和用途的内存 lease。超时、进程退出、身份变化或队列压力都会拒绝。

## 登记

登记只保存所有者、规范化路径、设备号、inode 等元数据，不读取私钥内容。替换文件或硬链接别名通过文件身份重新分类，不能绕过保护。

## Linux 与 macOS

Linux 使用 fanotify 权限事件；macOS 使用 Endpoint Security `AUTH_OPEN`。两者都保留人工 Block/Allow，不能把 SSH 读取改成无条件允许。`ssh-agent` 的签名操作仍按既有 agent 模型处理，不把签名本身伪装成文件读取。

## 验收

只使用临时生成的测试 key：普通读取应返回零字节并记录拒绝；明确批准后只在 lease 有效期内允许；lease 过期后再次读取必须重新确认。日志不得包含 key 内容。
